# Let's Go — releases

Downloads and the changelog of **Let's Go**, a crypto trading terminal. The source lives in a
private repository; this one holds only the released executables, one release per version:

- `LetsGo.exe` — the desktop app (Windows): the core and the interface in one window;
- `letsgo-core.exe`, `letsgo-core` — the core without a window, for a server (Windows, Linux);
- `SHA256SUMS` — the sums the app checks before it installs an update.

A running copy checks the latest release here once an hour and updates itself on a button.
